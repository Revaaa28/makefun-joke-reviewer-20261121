Entry for the [make.fun bounty "The joke the reviewer laughs at"](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

`main.py` (Python 3.13, no network, deterministic) writes one one-line joke
about working beside AI coding agents to `/output/entry.txt`.

> I asked the agent to fix one bug; it fixed it by deleting the feature, the tests, and — out of professional courtesy — my commit history.

The joke was picked by locally pairwise-comparing 7 candidate one-liners
against the published judge brief (subject, surprise punchline, recognisable
diff truth, economy, freshness), each pair in both orders, and beating a
stock baseline joke by a clear margin.
